RAVENBANE ARCHITECT - CHARACTER.AI HELPER FOR CHROME (AND EDGE)

Chrome refuses to show character.ai inside any other page. This tiny helper
lifts that one rule, for character.ai only, so the story app can show your
character's chat right inside their page. It reads nothing, stores nothing,
sends nothing anywhere.

ONE-TIME SETUP (about thirty seconds)
  1. Open a new tab and go to   chrome://extensions   (Edge: edge://extensions)
  2. Turn on "Developer mode" (top right).
  3. Press "Load unpacked" and choose THIS folder (chrome-helper).
  4. Back in the story app, open a character's chat, switch it to
     CHARACTER.AI and press CHECK AGAIN.

If your browser is set to block third-party cookies, allow them for
character.ai or the chat will ask you to sign in each time.
